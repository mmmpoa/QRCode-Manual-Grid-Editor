# QR Code Manual Grid Editor

A simple and interactive grid editor for creating custom QR codes. Toggle cells between black and white, automatically generate corner squares, and adjust the grid size.

## Features
- Click to toggle cells between black and white.
- Automatically generates the 3 corner squares required for QR codes.
- Adjustable grid size (21x21 to 40x40).
- Reset button to clear the grid.

## How to Use
1. Open the editor in your browser.
2. Adjust the grid size using the input field and click "Update Grid."
3. Click on the grid to toggle cells between black and white.
4. Use the "Reset Grid" button to clear the grid and start over.
